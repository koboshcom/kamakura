Instagram inspection accepts public instagram.com or www.instagram.com post and reel links. It removes share queries before extraction and uses no login, browser cookies, private cookies, retries or new provider settings. yt-dlp stays at the installed version, 2026.08.19.

A reel without metadata duration can be downloaded once through the existing byte meter, merged locally when needed and probed locally before selecting static or agentic coverage. Size, pixel, processing and wall-time limits still apply. Native short clips use the verified whole source; the non-native fallback shows only its requested opening interval and labels that limited coverage.

An image or image-only carousel that the extractor reports as having no video returns a precise unsupported result. This video tool does not inspect its images. An uploaded image can use the existing image pipeline instead.

No cookie-file environment mapping was added. The tested public reel works without authentication; the tested post is non-video. If another link explicitly requires authentication, it remains blocked. An HTTP 403 or empty response alone is not called a login requirement. Site failures have bounded, redacted diagnostics, and no automatic rate-limit retry.
