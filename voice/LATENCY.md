The input pump now schedules absolute 20ms deadlines instead of sleeping 20ms after each frame's processing. Work and scheduler overhead no longer accumulate into an ever-growing input backlog. After a long pause only the schedule rebases, never queued PCM. Existing freshness and backpressure limits remain.

The conversion is unchanged. It averages each four 48k stereo samples into one 24k mono sample. RMS classification at 180 only drives interruption and counters. Every accepted decoded frame, including quiet frames, is forwarded. There is no local input noise suppression, VAD input clipping, or speech-only input gate. Discord client settings and provider internals are outside this code.

Metrics are bounded fixed numeric counters, monotonic per-call first/last stage timestamps, and duration counts/sums/maxima. Python timestamps share a Python call origin; provider counters and local playback each use their own Node origin. Do not subtract timestamps across these origins. Receive-to-decode, conversion, input queue/send, Node output queue, Python output queue, and successful Discord writes are measured separately. Discord writes include silence and are not evidence of audibility.

A classified speech-end marker means an RMS transition to a quiet frame, not provider end-of-turn. The first provider output is a session-level marker, not necessarily a response to that speech. There is no guaranteed turn mapping. Previous calls lack these measurements, so historical live latency and live before/after percentiles remain unavailable.

The controlled offline fixture used identical synthetic PCM in two alternating runs per mode, 150 real frames each. Receive-to-serialization p50/p95 was 47.96/103.09ms with the old sleep-after-work loop and 19.98/20.97ms with absolute deadlines, with 300 samples per mode. Conversion/VAD/serialization p95 was 0.368/0.384ms. No PCM was skipped or reordered. This excludes Opus decode, real IPC, network, Live processing, and Discord playback and does not prove an end-to-end live improvement. No resampler or noise suppression was added.
